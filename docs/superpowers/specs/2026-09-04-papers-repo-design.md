## 4. 状态映射口径（源自本地清单 A/B/C 档位）

- ✅ 计划引用：A 档 / "必引"标注 / 一区正式版核心方法 / 专题综述
- 📥 候选补充：B、C 档；跨部位（脑/脊柱/MRI）；新刊或权威性较低
